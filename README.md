# ☀️ Sobre este Workspace

Este repositório contém meu ambiente completo de desenvolvimento no **Visual Studio Code**, utilizado diariamente para desenvolver aplicações, APIs REST, bancos de dados e projetos Full Stack.

O objetivo deste perfil é proporcionar um ambiente organizado, produtivo e confortável para longas sessões de desenvolvimento, reunindo minhas extensões favoritas, configurações, temas e ferramentas utilizadas durante meus estudos e projetos.

Este workspace é constantemente atualizado conforme descubro novas ferramentas que agregam ao meu fluxo de trabalho.

> **Observação:** O perfil é sincronizado através do **Settings Sync** do VS Code. Basta importar o perfil para obter automaticamente minhas configurações, extensões e preferências.

- Configurações


ou abra o arquivo **extensions.txt** para visualizar todas as extensões instaladas.
